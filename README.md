# 🤖 Chatbot using Python & NLP

This project is a simple AI-powered **Chatbot** built using **Python**, **Natural Language Processing (NLP)**, and **Machine Learning**. The chatbot is capable of understanding user inputs and providing intelligent responses based on pre-defined intents.

---

## 🧠 Features

- Intent classification using machine learning
- Clean conversational interface
- Easily extendable with custom intents and responses
- Trained using a bag-of-words model and neural networks
- Text preprocessing with NLP techniques
